上电前检查

  • 断电状态下确认模块 pin 1 方向，按本图逐线检查。
  • 万用表确认 ATK pin 2 相对 pin 1 为 3.3 V，禁止 5 V。
  • 确认 SCL=P410、SDA=P409，没有接反或与其他外设共用。
  • 当前阶段先验证芯片 ID：0x300A=0x56、0x300B=0x40。
  • ID 稳定通过 20 次后，再启用 PCLK、VSYNC、HREF 与 D0–D7。
关于直接插接 ATK 接口是 2×9，P8 是 2×8。为了确保 ATK pin 18 与 P8-16/P109 真正悬空，首次调试优先使用逐线跳接。只有确认手中模块 pin 18 电气上确为 NC 后，才考虑按 pin 3–18 对齐 P8-1–16。
