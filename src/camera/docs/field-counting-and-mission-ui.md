# 上位机田间计数与巡检参数

## 计数口径

网页同时显示三层结果：

- `wheat_count`：最新一帧的检测数，只用于查看当前画面。
- `mission_wheat_count`：当前运行周期内有效帧的累计数。
- `field_wheat_count`：当前设备记录的整田累计数。
- `counted_frame_count`：已经纳入累计的有效推理帧数。

每个成功完成的推理事务只计入一次，避免遥测每 250 ms 刷新时重复加数。当前运动固件
尚未接入，所以两个累计计数从本次上电开始同步累加；接入任务状态机后，开始新任务时
只复位 `mission_wheat_count`，换田或明确清场时才复位 `field_wheat_count`。

当前累计规则是“有效采样帧求和”。要把它作为整田真实总数，采样间隔必须根据摄像头
视场设置为不重复覆盖；如果相邻画面有重叠，同一麦穗可能被统计两次。后续可以在
板端加入位置关联、重叠区去重或轨迹跟踪，在不改变网页字段的前提下替换累计算法。

## 任务参数

上位机以试验田为单位配置：

- 田间行数、行间距、每行行程和采样间隔；每行采样点数由行程和间隔计算，不需要输入列数。
- 底盘速度、蛇形/同向路线和运动超时。
- 滑轨固定位置或多位置扫描；扫描模式使用扫描总距离和拍摄间隔计算位置。
- 机械停稳时间、推理超时和异常策略。

## 物理拍摄地图

网页地图采用车体固定坐标：向左为 `X+`，向前为 `Y+`。为了符合网页横屏显示，
`Y+` 画为从左向右，`X-` 画为从上向下。麦轮底盘在行尾只沿 `X-` 横移，不旋转
车体；下一条过道沿 `Y-` 返回，形成蛇形路线。

- 灰色带是 350 mm 小车过道，只绘制轨迹，不参与计数。
- 摄像头和滑轨位于小车右侧，拍摄区域画在对应过道的 `X-` 一侧。
- 每个规则方格代表一张完整照片覆盖的物理区域，不代表 YOLOX 的内部推理切片。
- 固定模式下，每个小车停车点只有一个拍摄方格；扫描模式下，按滑轨位置展开多个方格。
- 滑轨机械坐标和扫描行程限制为 `0..300 mm`。
- 换道横移量按 `过道宽度 + 滑轨扫描行程 + 单张照片横向地面视野` 规划。照片视野
  必须在最终安装高度下实测标定，不能把 300 mm 机械行程误当成完整覆盖宽度。
- 现阶段运动固件未接入时，地图明确显示为规划预览；只有区域索引与成功推理结果同时
  到达后，网页才会将方格标为完成并写入该区域计数。

区域索引由 `field_row + field_column + slide_position_index` 唯一确定；
`region_status` 表示待拍摄、移动中、采集中、推理中、完成或失败。运动状态机接入前
这些字段保持零值，网页不得依据遥测刷新次数伪造区域进度。现有 `FIELD.CSV` 保持
原有列格式；运动阶段接入区域持久化时应创建带独立版本的新区域日志，不能向旧文件
直接追加不同列数的记录。

串口屏工程中的字段和范围是后续 HMI 适配参考，不限制网页的完整任务模型。两者最终
都通过 `MissionPlanV1` 接入板端能力校验。

## 单个采样点时序

```text
底盘到位 -> 滑轨到位 -> 到位确认 -> 机械停稳
          -> 冻结当前帧 -> 拍摄/取帧 -> 完整推理
          -> 记录当前帧数 -> 更新任务累计和整田累计 -> 下一位置
```

在推理完成并写入记录前，任务状态机不得移动滑轨到下一位置。固定位置模式不自动移动
滑轨，只在该位置重复完成停稳、拍摄、推理和记录流程。
