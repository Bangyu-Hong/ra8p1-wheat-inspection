## A.3 关键处理流程

系统上电后依次检查 OV5640 和端侧模型。存储或网络不可用不会阻止本地检测；摄像头或模型初始化失败则进入故障状态。用户从串口屏提交样本编号后，系统读取 DHT11 和相对光照。DHT11 校验失败时将环境数据标记为无效，但不把错误值写入有效测量结果；光照越界时要求调整环境。

单帧采集采用超时保护。图像进入模型前计算平均亮度、暗像素比例、亮像素比例和离散拉普拉斯清晰度。质量不合格的图像不进入计数流程。合格图像按 320 × 320、重叠 64 像素分块，每块转换为 INT8 RGB 张量后调用 RUHMI 模型接口。模型局部坐标按分块缩放比例回映射至 640 × 480 原图，最后按置信度排序并执行全局 NMS，消除重叠区域内的重复候选框。

检测记录首先写入 TF 卡。网络在线时，RA8P1 使用带序号、长度和 CRC16-CCITT 的帧向 ESP8266 发送 JSON 载荷，并等待相同序号的 ACK。网络离线时先执行一次重连；重连或发送失败后，结果追加到 `/cache/pending.csv`，本地显示和下一次检测不受影响。

## A.4 错误处理路径

| 故障 | 判定位置 | 处理方式 |
|---|---|---|
| OV5640 无响应 | 芯片 ID 读取或 SCCB 写寄存器失败 | 停止进入检测流程，串口屏显示摄像头初始化失败 |
| 单帧采集超时 | 等待帧完成超过 `CAMERA_CAPTURE_TIMEOUT_MS` | 中止当前采集并进入可重试故障状态 |
| DHT11 校验失败 | 5 字节校验和不一致 | `valid=false`，保留检测流程，不使用错误温湿度值 |
| 光照不合格 | 相对光照不在校准阈值内 | 提示调整光照，不执行本次推理 |
| 图像过暗、过亮或模糊 | 图像质量指标越界 | 提示重新拍摄，不输出计数结果 |
| 模型调用失败 | RUHMI 初始化或推理接口返回错误 | 中止本次任务并显示推理错误 |
| TF 卡不可用 | 文件系统未就绪或写入失败 | 标记存储不可用，继续本地显示和网络上传 |
| 网络断开或 ACK 超时 | ESP8266 未在线或帧发送未确认 | 检测结果写入待上传缓存，系统离线运行 |

## A.5 模型生成文件说明

模型权重数组和 RUHMI 自动生成源文件不在报告正文中重复粘贴。报告保留 `wheat_model_port_init()` 与 `wheat_model_port_invoke()` 两个接口，并在提交版本中记录原始模型文件校验值、量化方式、RUHMI 转换版本、输入输出张量形状、scale、zero point 和生成日期。`wheat_ai.c` 中的通道顺序及零点处理必须与生成的张量元数据一致。
