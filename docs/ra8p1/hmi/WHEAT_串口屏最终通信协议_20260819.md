# WHEAT 串口屏最终通信协议

版本：2026-08-19  
适用工程：`WHEAT.HMI`  
适用页面：`main`、`carset`、`scanset`、`netset`

## 1. 通信双方

- 串口屏：淘晶驰 `TJC4827X243_011`，负责参数输入、按钮操作和状态显示。
- 上位控制端：本文指与串口屏直接连接的 CPU0/RA8P1 SCI3，负责协议解析、参数校验、任务控制和数据回写。
- 串口屏不得直接控制电机、PWM、GPIO 或导轨驱动器。

## 2. 串口配置与帧结束符

| 项目 | 配置 |
|---|---|
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | None |
| 字符编码 | UTF-8 |

两个方向使用不同的帧结束方式，不能混用：

| 方向 | 数据形式 | 帧结束符 |
|---|---|---|
| 串口屏 -> CPU0 | ASCII 协议帧 | 单字节 `0A`（LF） |
| CPU0 -> 串口屏 | 淘晶驰原生控件指令 | 三字节 `FF FF FF` |

串口屏上行帧不附加 `FF FF FF`。CPU0 下发控件指令不使用 `0A` 结束。

## 3. 串口屏发送给 CPU0 的数据

### 3.1 保存全部参数 `@P1`

底盘参数页或滑轨参数页点击“保存参数”时发送：

```text
@P1,SEQ,ROWS,AISLE_MM,PHOTO_WIDTH_MM,TRAVEL_MM,CAPTURE_GAP_MM,MAX_SPEED_MM_S,MOVE_TIMEOUT_MS,SLIDE_MODE,FIXED_MM,SCAN_MM,SLIDE_GAP_MM,SETTLE_MS,INFERENCE_TIMEOUT_MS,ERROR_POLICY\n
```

字段定义：

| 序号 | 字段 | 单位 | 当前范围/取值 | 说明 |
|---:|---|---|---|---|
| 1 | `SEQ` | 无 | 正整数 | 请求递增序号 |
| 2 | `ROWS` | 条 | 1～20 | 巡检过道数 |
| 3 | `AISLE_MM` | mm | 100～2000 | 小车过道宽度 |
| 4 | `PHOTO_WIDTH_MM` | mm | 当前默认 300 | 单张图像横向覆盖宽度，当前不在页面调节 |
| 5 | `TRAVEL_MM` | mm | 100～5000 | 每条过道行程 |
| 6 | `CAPTURE_GAP_MM` | mm | 50～2000 | 小车沿 Y 方向拍摄间隔 |
| 7 | `MAX_SPEED_MM_S` | mm/s | 50～500 | 小车最大速度 |
| 8 | `MOVE_TIMEOUT_MS` | ms | 当前默认 30000 | 单次运动超时 |
| 9 | `SLIDE_MODE` | 无 | 0 或 1 | 0=固定模式，1=多位置扫描 |
| 10 | `FIXED_MM` | mm | 0～300 | 固定模式位置；扫描模式必须为 0 |
| 11 | `SCAN_MM` | mm | 10～300 | 扫描总行程；固定模式必须为 0 |
| 12 | `SLIDE_GAP_MM` | mm | 10～300 | 滑轨拍摄间隔；固定模式必须为 0 |
| 13 | `SETTLE_MS` | ms | 当前默认 800 | 机械停稳时间 |
| 14 | `INFERENCE_TIMEOUT_MS` | ms | 当前默认 5000 | 识别超时 |
| 15 | `ERROR_POLICY` | 无 | 当前为 0 | 当前错误处理策略 |

多位置扫描示例：

```text
@P1,5,2,350,300,1200,300,200,30000,1,0,300,100,800,5000,0\n
```

固定模式示例（固定位置 40 mm）：

```text
@P1,6,2,350,300,1200,300,200,30000,0,40,0,0,800,5000,0\n
```

CPU0 收到后必须：

1. 检查字段数量恰好为 15 个数值字段。
2. 检查所有字段能完整转换为整数。
3. 检查范围和模式互斥关系。
4. 校验成功后应用参数并回写 `sys2=2`。
5. 校验失败时保持原参数并回写 `sys2=3`。
6. 收到 `@P1` 只保存/应用参数，不得自动启动巡检。

### 3.2 启动自动巡检 `@C1,START`

主页点击“开始巡检”，且参数状态已经是“已应用”时发送：

```text
@C1,SEQ,START\n
```

示例：

```text
@C1,7,START\n
```

CPU0 收到后根据最近一次通过校验的 `@P1` 参数启动自动巡检。

### 3.3 单次采集识别 `@C1,INFER`

主页点击“采集识别”时发送：

```text
@C1,SEQ,INFER\n
```

示例：

```text
@C1,8,INFER\n
```

该命令执行一次采集和识别，不启动完整巡检任务。

### 3.4 正常停止 `@C1,STOP`

普通停止任务时发送：

```text
@C1,SEQ,STOP\n
```

示例：

```text
@C1,9,STOP\n
```

CPU0 应有序停止当前任务、取消后续动作并进入安全空闲状态。

### 3.5 紧急停止 `@E1`

红色“急停”按钮应发送：

```text
@E1,SEQ\n
```

示例：

```text
@E1,10\n
```

`@E1` 的优先级高于所有其他命令。CPU0 收到后必须立即停止小车、滑轨、拍照及识别动作。

注意：`@C1,SEQ,STOP` 是正常停止，`@E1,SEQ` 是紧急停止。若当前画面只有一个红色“急停”按钮，该按钮必须使用 `@E1`；不能用 `STOP` 代替急停。

### 3.6 标记滑轨软件零点

滑轨页面点击“设置零点”时发送：

```text
@J1,SEQ,SLIDE,SET_ZERO,0\n
```

示例：

```text
@J1,11,SLIDE,SET_ZERO,0\n
```

含义：将滑轨当前位置记录为软件零点，不驱动滑轨移动。CPU0 应检查滑轨是否处于允许标零的安全状态。

### 3.7 网络命令

连接 Wi-Fi：

```text
@N,SSID,PASSWORD\n
```

示例：

```text
@N,Wheat_WiFi,123456789\n
```

断开 Wi-Fi：

```text
@D\n
```

查询网络状态：

```text
@G\n
```

当前协议不支持转义，SSID 和密码不得包含英文逗号、回车或换行。CPU0 不得在调试日志中输出明文密码。

## 4. CPU0 发送给串口屏的数据

### 4.1 通用发送格式

CPU0 每次发送一条淘晶驰控件指令，并在末尾追加：

```text
FF FF FF
```

示例：

```text
main.nCount.val=12 FF FF FF
```

中文字符串必须按 UTF-8 编码发送。建议需要异步更新的控件设置为全局作用域，并使用完整页面名访问。

### 4.2 环境和检测数值

| 数据 | CPU0 下发指令示例 | 显示规则 |
|---|---|---|
| 麦穗数量 | `main.nCount.val=12` | 整数 |
| 温度 25.6℃ | `main.xTemp.val=256` | 发送实际值的 10 倍，`vvs1=1` |
| 湿度 63.8% | `main.xHum.val=638` | 发送实际值的 10 倍，`vvs1=1` |
| 相对光照 72% | `main.nLight.val=72` | 0～100 整数 |

光照使用百分比，不使用 `lx`。CPU0 应先把传感器原始值换算为 0～100。

### 4.3 检测状态

当前页面只使用以下三个主状态：

```text
main.tDetectState.txt="等待检测"
main.tDetectState.txt="检测中"
main.tDetectState.txt="检测完成"
```

不要向页面发送“优质小麦”、品质等级或分段扫描进度；当前页面不使用 `tQuality`，也不要求 CPU0 更新 `tDetSub`。

推荐时序：

| 时机 | 指令 |
|---|---|
| 上电且空闲 | `main.tDetectState.txt="等待检测"` |
| 开始采集或巡检 | `main.tDetectState.txt="检测中"` |
| 结果更新完成 | `main.tDetectState.txt="检测完成"` |

### 4.4 主页检测信息

当前实际控件：

| 控件 | 用途 | 示例指令 |
|---|---|---|
| `tCpu1` | 主控连接状态 | `main.tCpu1.txt="主控在线"` |
| `tTime` | 检测耗时 | `main.tTime.txt="耗时:128 ms"` |
| `tSample` | 样本编号 | `main.tSample.txt="样本:0001"` |
| `tUpload` | 检测/上传状态 | `main.tUpload.txt="检测完成"` |

这些字符串属于显示内容，CPU0 必须限制长度，并对双引号、反斜杠和不可见控制字符进行过滤，不能把未经处理的外部字符串直接拼进控件指令。

### 4.5 参数校验结果

CPU0 收到 `@P1` 后回写全局参数状态：

| 结果 | 指令 | 含义 |
|---|---|---|
| 校验并应用成功 | `sys2=2` + `FF FF FF` | 页面显示“已应用” |
| 校验失败 | `sys2=3` + `FF FF FF` | 页面显示“被拒绝” |

`sys2` 状态约定：

```text
0 = 未保存
1 = 校验中
2 = 已应用
3 = 被拒绝
```

如需当前页面立即刷新文字，可在成功时额外发送对应页面指令：

```text
tSaveSt.txt="已应用" FF FF FF
tSaveSt.pco=20147 FF FF FF
```

或在滑轨页面发送：

```text
tScanSt.txt="已应用" FF FF FF
tScanSt.pco=20147 FF FF FF
```

失败时使用：

```text
tSaveSt.txt="被拒绝" FF FF FF
tSaveSt.pco=60042 FF FF FF
```

### 4.6 网络状态回写

CPU0 处理 `@N`、`@D` 或 `@G` 后，直接更新网络页面：

```text
netset.tNetState.txt="已连接" FF FF FF
netset.tIPAddr.txt="192.168.1.105" FF FF FF
```

断开或失败时可发送：

```text
netset.tNetState.txt="未连接" FF FF FF
netset.tIPAddr.txt="-" FF FF FF
```

## 5. 完整通信流程

### 5.1 参数保存并启动巡检

```text
串口屏 -> CPU0：@P1,...\n
CPU0 校验成功
CPU0 -> 串口屏：sys2=2 + FF FF FF
用户点击开始巡检
串口屏 -> CPU0：@C1,SEQ,START\n
CPU0 -> 串口屏：main.tDetectState.txt="检测中" + FF FF FF
任务完成
CPU0 -> 串口屏：数量、温湿度、光照、耗时和样本编号等控件指令
CPU0 -> 串口屏：main.tDetectState.txt="检测完成" + FF FF FF
```

### 5.2 单次采集识别

```text
串口屏 -> CPU0：@C1,SEQ,INFER\n
CPU0 -> 串口屏：main.tDetectState.txt="检测中" + FF FF FF
CPU0 完成采集和识别
CPU0 -> 串口屏：main.nCount.val=结果 + FF FF FF
CPU0 -> 串口屏：main.tDetectState.txt="检测完成" + FF FF FF
```

## 6. CPU0 解析与发送要求

1. 接收端按字节累计，遇到 `0A` 才形成一帧。
2. 接收缓冲区溢出、字段数量错误、整数转换失败或越界时必须丢弃整帧。
3. `SEQ` 用于识别重复请求；不能因为串口重发而重复启动危险动作。
4. `@E1` 必须在任何任务状态下优先处理。
5. UART 中断只收发字节，不在中断中解析长字符串、控制电机或写 Flash。
6. CPU0 下发每条 HMI 指令都必须独立追加 `FF FF FF`。
7. CPU0 下发中文必须使用 UTF-8，不得使用 GBK。
8. 参数未通过 `@P1` 校验时，不得执行 `START`。
9. 收到 `STOP` 或 `@E1` 后，必须取消尚未执行的拍照、识别和运动步骤。

## 7. 当前有效协议汇总

| 方向 | 协议/指令 | 作用 |
|---|---|---|
| HMI -> CPU0 | `@P1,...\n` | 保存和校验全部参数 |
| HMI -> CPU0 | `@C1,SEQ,START\n` | 开始自动巡检 |
| HMI -> CPU0 | `@C1,SEQ,INFER\n` | 单次采集识别 |
| HMI -> CPU0 | `@C1,SEQ,STOP\n` | 正常停止 |
| HMI -> CPU0 | `@E1,SEQ\n` | 紧急停止 |
| HMI -> CPU0 | `@J1,SEQ,SLIDE,SET_ZERO,0\n` | 标记滑轨软件零点 |
| HMI -> CPU0 | `@N,SSID,PASSWORD\n` | 连接 Wi-Fi |
| HMI -> CPU0 | `@D\n` | 断开 Wi-Fi |
| HMI -> CPU0 | `@G\n` | 查询 Wi-Fi 状态 |
| CPU0 -> HMI | `控件指令 + FF FF FF` | 更新数值、文字和参数状态 |

以下内容不属于当前协议，不应继续使用：

```text
@A,...
@E
tQuality
“优质小麦”等品质文字
PAUSE / RESUME
```
