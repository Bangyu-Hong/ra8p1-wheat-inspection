# 队友任务拆分与验收清单

## 1. 分工总原则

两位队友可以并行开发，但不能各自修改视觉、网页、任务和运动数据的定义。系统只有一份任务参数、
一份运行状态和一套命令语义：M85 是任务与业务状态权威，M33 是运动与安全状态权威，串口屏和网页
都是显示与控制入口。

## 2. 底盘队友：M33 运动控制

### 开始前必读

1. `00_先看_交付总览.md`
2. `01_项目总体方案与系统架构.md`
3. `04_底盘_JY61P_编码器_PID_交接方案.md`
4. `06_开发原则与注意事项.md`
5. `精选参考资料/底盘参考/` 中的五份指南和 `Core` 精选源码

### 负责范围

- 建立 RA8P1 双核 Solution 和 CPU1/Cortex-M33 工程；当前 M85 主工程保持可回退。
- 四路 PWM、方向、使能和四路 GPT AB 相编码器驱动。
- JY61P IIC1 非阻塞驱动、样本有效性、归零和掉线处理。
- 麦轮正/逆运动学、四轮轮速 PID、X/Y/Yaw 位姿外环和停稳判定。
- ZDT42 滑轨 SCI8、回零、软硬限位、到位和故障状态。
- M85/M33 IPC、心跳、协议版本、序号幂等和失联停车。
- 急停、驱动故障、堵转、编码器异常和控制周期超时的安全停机。

### 不负责范围

- 不重写摄像头、LCD、AI、ESP8266、SD、网页或串口屏业务。
- 不直接解析网页 JSON 或 HMI 控件名。
- 不让 M85 的调试暂停造成电机维持上一占空比。

### 分阶段交付物

| 阶段 | 交付物 | 必须证据 |
| --- | --- | --- |
| A | M33 空工程、双核启动、IPC 心跳 | 两核版本与心跳日志；M85 单核镜像仍可回退 |
| B | 四轮开环与编码器 | 单轮方向表、一圈计数、急停后 PWM=0 |
| C | 100 Hz 四轮轮速闭环 | 四轮目标/实际曲线、控制周期 P99/max |
| D | JY61P I2C 与融合 | yaw/gyro/数据年龄、拔线降级日志 |
| E | X/Y/Yaw 位姿控制 | 100/300/1000 mm 前进和横移重复误差 |
| F | ZDT42 与整车任务接口 | 回零、限位、到位、停稳和故障测试 |

每一阶段必须提交源码、配置文件、引脚表变化、构建方法、测试记录和可回退镜像。不要只交一个 ELF。

## 3. 串口屏队友：SCI3 HMI 适配

### 开始前必读

1. `00_先看_交付总览.md`
2. `02_当前进度与验收状态.md`
3. `05_串口屏开发交接方案.md`
4. `06_开发原则与注意事项.md`
5. `精选参考资料/串口屏参考/`

### 负责范围

- 在当前主工程中实现 SCI3 非阻塞收发、帧解析、超时和错误计数。
- 从统一遥测快照显示计数、环境、网络、SD、AI、任务和运动状态。
- 将页面操作转换成统一命令，不直接改内部全局变量。
- 实现环境、巡检、调试三类核心页面；页面切换不能改变任务状态。
- 对开始、暂停、停止、清零、手动微调建立清楚的按钮反馈和能力门禁。
- 对发送队列做合并/限速，禁止每次循环全量刷新所有控件。

### 不负责范围

- 不实现第二套巡检参数结构或第二套累计计数。
- 不在 HMI 层驱动 PWM、滑轨、摄像头或模型。
- 不把 HMI 页面号和控件名传播到业务层。
- 不绕过运动未就绪、AI 忙、急停等状态门禁。

### 分阶段交付物

| 阶段 | 交付物 | 必须证据 |
| --- | --- | --- |
| A | SCI3 收发与帧解析 | 连续收发、粘包/拆包、错误帧测试 |
| B | 状态显示 | 环境、计数、网络、SD、AI 与网页一致 |
| C | 参数与命令 | 修改/下发/应用状态清楚，危险命令有确认 |
| D | 运动页面 | 底盘和滑轨能力关闭时禁用，接入后反映真值 |
| E | 长稳与回归 | 高频刷新无阻塞，摄像头/LCD/AI/网络不退化 |

## 4. 主工程集成顺序

1. 先冻结当前 M85 单核恢复点，不覆盖交付包固件。
2. 底盘先完成双核启动、心跳和安全停车，再接真实电机。
3. 串口屏先用模拟状态验证协议，不等待底盘全部完成。
4. M33 状态通过统一 IPC 进入 `app_telemetry_snapshot_t`。
5. 网页和串口屏同时消费同一快照；控制命令进入同一仲裁入口。
6. 最后接整田状态机：移动 -> 减速 -> 停稳 -> 冻结画面 -> 推理 -> 记录 -> 下一位置。

## 5. 合并前共同门禁

- Release 构建 0 error，新增代码不新增警告。
- 摄像头 640x480、LCD 实时画面、按键冻结/恢复、AI 推理全部回归。
- ESP8266 网页可访问，断网不阻塞运动和本地任务。
- SD 不存在或写失败时能继续安全巡检并明确报告降级。
- 串口屏拔掉、JY61P 拔掉、M85 暂停、M33 复位均有确定行为。
- 网页、串口屏、调试串口显示的任务 ID、区域、计数和运动状态一致。
- 任何故障恢复不能重复执行已完成位移或重复累计同一物理区域。

## 6. 第一轮建议目标

比赛时间有限，第一轮先实现：低速麦轮前后/横移闭环、保持 yaw=0、300 mm 滑轨、区域到位拍照、
串口屏核心状态和开始/暂停/停止。EKF、云端大模型、历史地图回放和复杂参数编辑全部后置。
