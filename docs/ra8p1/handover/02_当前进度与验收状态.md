# 当前进度与验收状态

## 1. 当前里程碑

项目已经完成“视觉与显示基线”和“环境/联网/存储/网页底座”，正在进入“运动控制与串口屏集成”
阶段。底盘、JY61P、ZDT42 自动巡检和串口屏板端协议尚未完成。

## 2. 状态说明

- **实板通过**：当前硬件和已烧录版本已经观察到目标行为。
- **代码通过**：主机测试/构建通过，但仍有专项实板或故障注入门禁。
- **规划冻结**：接口和资源已确定，产品代码尚未启用。
- **未完成**：不能对外宣称具备该功能。

## 4. 当前网页的真实能力

网页可显示摄像头/AI/环境/网络/SD 状态，可生成试验田规划图，可保存浏览器本地草案，并预留
任务、底盘和滑轨按钮。由于固件没有发布 `RA8P_CAPABILITY_MOTION` 和
`RA8P_CAPABILITY_SLIDE`，运动按钮应保持禁用；网页不能驱动尚未实现的硬件。

小车图标依据 `field_row` 和 `field_column` 放置。当前这两个字段没有运动控制模块更新，所以
图标停在起点。这是有意的能力门禁，不是网页绘图错误。

## 6. 测试与构建现状

- 完整主机测试通过。
- JavaScript 语法、HTML 元素 ID、网页 CRC 检查通过。
- 桌面布局和 390×844 手机布局通过浏览器检查。
- 强制 Release 构建通过，0 个编译错误。
- 工程仍有 FatFs、RUHMI、newlib 等生成代码警告；当前没有证据表明它们是本轮功能错误，
  但接管者不能让新增代码继续增加同类警告。

## 7. 不能误报为完成的内容

- 当前模型“可以运行”不等于“小麦识别准确率通过”。
- SD 软件链路存在不等于“所有拔卡、掉电、满卡门禁通过”。
- 网页画出路线不等于真实小车已经定位或运动。
- `actual_position_mm` 字段存在不等于编码器已经接入。
- JY61P 支持 I2C 不等于手中模块已完成 I2C 模式和电压验收。
- 预留双核接口不等于 CPU1/M33 镜像已经创建。

## 8. 当前版本的回退边界

如果底盘或串口屏开发破坏摄像头、LCD、AI 或网络，优先烧回本交付包中的 Release SREC。新双核
Solution 必须独立保留，不能直接把当前可运行单核工程改到无法恢复。
