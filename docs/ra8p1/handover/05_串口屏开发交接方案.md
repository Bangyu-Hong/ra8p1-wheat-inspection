# 串口屏开发交接方案

## 1. 范围和所有权

串口屏队友负责屏幕页面、屏幕端控件事件和 RA8P1 的 HMI 适配层，不负责重新定义任务逻辑、
运动控制、计数规则、Wi-Fi AT 驱动或存储格式。

系统真值在 RA8P1：

- 串口屏显示统一状态快照。
- 屏幕控件只产生“请求”，由应用层校验后决定是否执行。
- 网页和串口屏修改的是同一份 `MissionPlanV1`，不能各维护一套互相覆盖的参数。
- 屏幕掉电、卡死或拔线时，摄像头、AI、SD、网络和安全停车继续工作。

## 2. 串口与接线冻结

| 信号 | RA8P1 | 扩展板 | 连接方向 |
| --- | --- | --- | --- |
| HMI TX | P905 / RXD3 | P6-31 | 屏幕发送 -> RA8P1 接收 |
| HMI RX | P310 / TXD3 | P6-33 | RA8P1 发送 -> 屏幕接收 |
| GND | GND | P10 | 必须共地 |
| 电源 | 按屏幕规格 | 独立核对 | 逻辑电平和电源电压不能混淆 |

SCI3 的具体波特率在接入前依据屏幕工程手册冻结，建议优先 115200 8N1。不得改用已被占用的
SCI0、SCI8、SCI9 或 LCD 使用的 P714/P715。

## 4. 首版页面建议

### 总览页

- 当前照片计数、本次巡检累计、整田累计。
- 温度、湿度、光照。
- 摄像头、AI、SD、网络、底盘、滑轨状态。
- 当前过道/拍摄点/滑轨位置和任务进度。

### 任务页

- 过道数、每行行程、沿 Y 拍摄间隔、速度上限。
- 滑轨固定/扫描模式、固定位置或扫描行程/间隔。
- 停稳时间、推理超时和错误策略。
- 参数摘要、校验结果、应用状态。

### 手动控制页

- 小车前/后/左/右、停止，显示单次微调距离。
- 滑轨回收/伸出/停止，显示单次微调距离。
- 单帧识别、恢复预览。
- 手动命令只有在安全状态和能力允许时启用。

### 巡检控制页

- 开始、暂停/继续、停止。
- 当前区域、完成/总区域、当前与累计计数。
- 运动/停稳/拍摄/推理/记录状态。

### 网络设置页

- SSID、密码输入和连接请求可后置；密码不回显、不进入普通日志。
- 当前 IP、连接状态和错误码。
- 当前运行固件尚未完成运行时 Wi-Fi A/B 配置，屏幕 UI 不得假装已经保存成功。

### 调试页

- 固件/模型版本、故障标志、IMU/编码器健康、网络/SD错误。
- 调试页只读为主，不提供任意内存、GPIO 或 PWM 操作。

## 5. 板端 HMI 协议要求

不要到处拼厂商控件字符串。建立一个 `hmi_service`：

```text
app snapshot -> hmi adapter -> 厂商页面/控件命令 -> SCI3 TX队列
SCI3 RX -> 有界帧解析 -> hmi request -> app command validator
```

项目层帧至少包含同步头、版本、类型、序号、长度、负载和 CRC16。若屏幕本身只支持文本命令，
也必须在适配层限制长度、页面、控件 ID 和参数范围；收到粘包、拆包、噪声或超长数据时丢弃并
计数，不能写越界。

普通数值只在变化时或低频刷新，建议 5-10 Hz；告警、任务状态变化和按钮 ACK 立即发送。串口
发送队列满时合并旧遥测，不能丢急停/故障/确认。

## 6. 与网页对齐的字段

- `wheat_count`、`mission_wheat_count`、`field_wheat_count`、`counted_frame_count`。
- 温度、湿度、光敏、数据有效性和年龄。
- `camera_state`、`ai_state`、`sd_state`、`network_state`、`fault_flags`。
- `field_row`、`field_column`、`slide_position_index`、`region_status`。
- 后续 `pose_x/y/yaw`、目标位姿、运动状态、停稳和 IMU/编码器有效性。
- 任务参数使用 `MissionPlanV1` 相同单位、范围和默认值。

串口屏不必画完整可缩放地图；比赛时间有限，首版可用当前区域、进度条和简化网格表达。网页
继续承担完整田间分布地图。

## 7. 命令和安全规则

- 所有数值先在 HMI 层解析，再交应用层范围校验。
- 运动中禁止随意改几何参数；停止或明确暂停后才能应用。
- 开始任务前显示摘要并确认；停止和急停必须始终可达。
- 相同序号的重复按钮事件不得重复执行位移。
- HMI 失联不能清空任务真值，重连后先请求完整状态快照。
- 屏幕不能直接控制 PWM、方向 GPIO 或驱动使能。

## 8. 验收顺序

1. PC 串口工具验证 SCI3 收发和粘包/拆包解析。
2. 只接屏幕，完成总览遥测显示和断电重连。
3. 完成任务参数读取/编辑/校验，但底盘能力未发布时返回不支持。
4. 底盘接入后验证手动控制、开始/暂停/停止和重复命令。
5. 同时打开网页和串口屏，确认两端显示同一真值，参数冲突有确定规则。
6. 拔掉屏幕、发送噪声和高频操作，摄像头/LCD/AI/底盘安全不受影响。
