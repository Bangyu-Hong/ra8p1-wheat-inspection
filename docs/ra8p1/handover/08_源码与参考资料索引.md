# 源码与参考资料索引

## 1. 可信度顺序

发生冲突时按以下顺序判断：

1. 当前实板测量、CPKHMI 原理图、RA8P1 硬件手册、外设规格书。
2. `workspace/camera/configuration.xml` 和 FSP 6.5.0 生成配置。
3. Renesas、Arm、Espressif、维特等厂商官方当前文档。
4. `.trellis/spec/embedded/` 项目规范和本交付包。
5. CPK/Titan/正点原子/商家示例、STM32 课设和底盘参考工程。

参考工程用于借鉴协议、状态机和算法，不能覆盖当前板卡引脚与 FSP API。

## 7. 底盘参考工程

完整路径：

`kuozhanmokuai/32底层代码(footbase轮子正装魔女开发板25M小轮子95mm)/`

重点阅读：

- `IMU_GUIDE.md`：WT901 UART 帧、校验、角度和归零；JY61P I2C 不能照搬其串口初始化。
- `ROS_Navigation_MCU_Guide.md`：麦轮运动学、100 Hz PID、50 Hz 里程计和 IMU 融合思想。
- `SYSTEM_GUIDE.md`、`PROTOCOL_GUIDE.md`、`接线文档.md`：模块边界和故障排查。
- `Core/Src/tim.c`：四轮 PWM、编码器读取和增量式 PID。
- `Core/Src/main.c`：调度和里程计参考。
- `Core/Inc/main.h`、`Core/Inc/tim.h`：方向反转、PID 参数和接口。

该工程是 STM32F407/HAL，不能直接加入 RA8P1 工程。复制算法前先剥离 HAL、引脚和阻塞延时。

## 10. JY61P 在线资料（2026-08-18核验）

- 厂商产品页：https://www.wit-motion.cn/proztmz/37.html
- 厂商产品资料入口：https://wit-motion.yuque.com/wumwnr/docs/np25sf
- I2C 寄存器读取参考：https://wiki.lckfb.com/zh-hans/dmx/module/sensor/jy61p-measurement-sensor.html

已核验事实：JY61P 支持串口和 I2C、最高 200 Hz、I2C 参考地址为 7-bit `0x50`；六轴动态
航向存在积分累计误差。实际供电、12Pin 丝印、I2C 模式和上拉必须在手中模块上再次确认。
