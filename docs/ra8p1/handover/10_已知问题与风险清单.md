# 已知问题与风险清单

## 1. 使用方法

本清单用于防止接管者把“代码存在”“能够运行”和“实板验收通过”混为一谈。优先级分为：

- P0：可能造成运动失控、程序无法恢复或比赛主功能不可用，必须先解决。
- P1：影响可靠性、检测质量或展示效果，应在整机联调前解决。
- P2：可以演示但体验或维护性不足，可按时间安排。

## 2. P0 风险

| 风险 | 当前事实 | 影响 | 规避/关闭条件 |
| --- | --- | --- | --- |
| 双核运动安全尚未实现 | 当前仅 M85 产品工程可运行 | 调试暂停或失联时若电机由 M85 直控会失去实时性 | M33 独立安全状态机、硬件急停、心跳失联停车全部实测 |
| 底盘引脚仍是预留 | PWM/编码器/方向资源尚未接实车核对 | 方向错、资源冲突或编码器无法计数 | 原理图+FSP+单轮架空三方确认并更新权威引脚表 |
| JY61P 实物电气未验收 | 已确认协议支持 I2C，供电/丝印/上拉需看手中模块 | 接错电压、总线不稳定或没有进入 I2C 模式 | 对照实物手册测电压，100 kHz 连续读和拔线测试通过 |
| 当前模型精度不合格 | YOLOX/Ethos-U55 链路能跑，但存在漏检/偏差 | 小麦总数没有可信度 | 固定测试集上 FP32/INT8 指标和实拍计数达到新基线 |
| 自动巡检状态机未完成 | 网页只有规划和控制预留 | 小车不能按区域自动采集计数 | 完成移动-停稳-拍照-推理-记录-前进全链路实测 |

## 3. P1 风险

| 风险 | 当前事实 | 影响 | 规避/关闭条件 |
| --- | --- | --- | --- |
| 六轴 IMU 航向漂移 | JY61P 无磁力计，动态 yaw 会累计误差 | 长距离巡检车头和坐标逐渐偏移 | 编码器+gyro/yaw 融合、停稳校正；必要时增加外部基准 |
| 麦轮在土壤打滑 | 编码器只能测轮子，不直接测地面位移 | X/Y 里程计产生系统误差 | 低速斜坡、重复标定、区域容差；预留视觉/标志校正 |
| SD 故障门禁未完整 | 软件链路已集成，拔卡/掉电/满卡未全部验收 | 日志丢失或恢复慢 | 故障注入、尾部恢复、容量轮转和明确降级状态通过 |
| 网络长稳未充分覆盖 | ESP8266 入网和板端网页已实板通过 | 多终端、换网或断线时页面状态不一致 | 控制租约、重连、IP 更新、压力运行门禁通过 |
| 1 m 摄像头 FPC 不可靠 | 短线正常，长线出现条纹/黑屏 | 结构安装距离受限 | 比赛使用短线；若必须长线则重新做信号完整性硬件方案 |
| LCD 仍有轻微刷新压力 | 当前已明显改善 | 加入双核/运动遥测后可能闪烁或掉帧 | 集成后测显示周期与总线占用，保持批量写和非阻塞调度 |
| OSPI/SDRAM Cache 所有权 | 单核现状可运行，双核共享尚未设计 | 脏缓存导致模型、帧或 IPC 数据不一致 | 明确每段所有者、非缓存区或 clean/invalidate 边界 |
| FSP Generate 回归 | 历史上生成曾改变 CEU `bytes_per_pixel` | 摄像头条纹、方向或步长错误 | 每次生成后运行配置检查并实板回归，不手改生成文件 |

## 4. P2 风险

| 风险 | 当前事实 | 影响 | 处理建议 |
| --- | --- | --- | --- |
| 网页地图尚无真实位姿 | 只显示规划区域 | 小车图标停在起点 | M33 发布 `x/y/yaw` 后再接，不用前端假动画 |
| 运行时换 Wi-Fi 未完成 | 凭据编译/配置进板 | 换场地需重新配置或烧录 | 后续做串口屏/临时 AP 配网，比赛前固定热点可先用 |
| 串口屏尚未接入 | SCI3 和 HMI 资料已预留 | 本地交互缺失 | 按专项交接实现，复用网页字段和命令 |
| DHT11/光敏需现场标定 | 驱动和基础采样已通过 | 百分比与实际环境量可能不准确 | DHT11 保持约 1 s，光敏做明暗两点标定 |
| 生成代码既有警告 | 当前 Release 0 error，但有三方/生成代码警告 | 容易掩盖新增问题 | 保存基线，禁止新增业务警告；不为清零盲改三方源码 |
| 网页功能偏多 | 调试和比赛展示混在一个页面 | 现场操作信息密度高 | 增加演示/调试模式，暂不引入账号系统 |

## 5. 存储与凭据风险

- `src/esp_at_credentials.h` 含 Wi-Fi SSID/密码，不进入 Git、交付压缩包或普通日志。
- SREC/ELF 可能包含编译期字符串；若产品镜像曾编入真实凭据，外发前必须重新用演示凭据构建。
- `camera.srec` 是 S-record 文本，14 MB 文件大小不代表占用 14 MB 内部 MRAM；程序同时使用内部 MRAM、
  OSPI、内部 SRAM 和 SDRAM。
- 不删除原始工作区中的模型、数据集和参考 SDK；交付包只精选复制，完整资料通过索引定位。

## 6. 每次集成后的快速回归

1. 上电画面正常，无彩条、黑屏和明显像素顺序错误。
2. 连续实时显示，USER 冻结/推理/恢复至少 5 轮。
3. 网页手机和电脑均可打开，环境/网络/SD 状态持续更新。
4. 无 SD、无 Wi-Fi、无串口屏时主视觉和本地任务仍可运行。
5. 接运动后，急停、M85 暂停、IPC 超时均使 PWM 归零。
6. 停稳信号只能由实际位置、角度和速度窗口产生，不能用固定延时冒充。

## 7. 风险关闭记录格式

关闭风险时记录：日期、固件 Git/压缩包哈希、硬件版本、接线版本、测试条件、重复次数、原始日志
路径和结论。单次“看起来正常”只算探索结果，不算长稳门禁。
