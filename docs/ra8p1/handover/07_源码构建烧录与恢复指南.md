## 2. 从交付包恢复源码

`源码快照/workspace_camera_source_20260818.zip` 是当前产品工程的完整可开发快照，包含模型生成
源码、FSP/RA 源、配置、测试和工具，不包含：

- `Debug/`、`Release/` 构建目录。
- `.pytest_cache/`。
- 本地 Wi-Fi 凭据 `src/esp_at_credentials.h`。
- 临时硬件日志。

解压到新的工作目录后，将根目录命名为 `camera`。若要直接继续当前仓库，优先保留原
`workspace/camera`，在独立目录对比后再合并，不要直接覆盖用户现有工作树。

## 3. 配置本地 Wi-Fi

源码快照只含示例，不含密码。在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File `
  .\workspace\camera\tools\configure_esp8266_credentials.ps1
```

输入 2.4 GHz SSID 和密码。生成的 `src/esp_at_credentials.h` 必须继续保持 Git 忽略。

## 5. FSP Generate

只有修改 `configuration.xml`、Stack、引脚、时钟或中断时才需要重新 Generate：

1. 用 e² studio 打开 `workspace/camera`。
2. 打开 `configuration.xml`，完成配置并保存。
3. 点击 `Generate Project Content`。
4. 等待生成完成，关闭 e² studio，避免占用构建/调试工具。
5. 运行 `check_fsp_generated_contract.ps1`，检查 CEU、SDHI、OSPI 和引脚。
6. Clean Build Debug/Release。

如果 Generate 后出现 CEU `bytes_per_pixel` 从 1 变 2、引脚被删或 Stack 意外变化，先修
`configuration.xml`，不要手改 `ra_gen` 掩盖问题。

## 6. 构建

项目当前支持 e² studio Managed Build。命令行直接构建前要确认 Renesas 工具链环境已经加载。
已有环境可使用：

```powershell
make -C workspace\camera\Release clean all
```

或在 e² studio 中选择 `Project -> Clean`，再 Build `Release`。大改后检查 Problems 中错误为 0，
再核对 `camera.map`、`camera.elf` 和 `camera.srec` 时间确实更新。已有生成代码警告不能冒充新代码
错误，但也不能只看退出码忽略真实 error。

## 7. 命令行烧录

当前镜像位于 `可烧录固件/camera.srec`，可直接运行：

```powershell
powershell -ExecutionPolicy Bypass -File `
  .\可烧录固件\flash_current_release.ps1
```

脚本会定位 J-Link、连接 CPU0、复位/暂停、写入内部 MRAM 与 OSPI、校验并启动。烧录时保持
板卡和 J-Link 供电稳定，关闭 e² studio/J-Link GDB Server，不按复位、不拔线。

成功日志必须包含：

```text
Device "R7KA8P1KF_CPU0" selected
Downloading file ... camera.srec
Flash download ... Program ... Verify
O.K.
J-Link>g
```

J-Link 进程退出码为 0 且日志有 `O.K.` 才算本次下载完成。完整跨 TrustZone 边界验收还要遵循
`workspace/camera/docs/ra8p1-mram-programming.md`，确认 Code MRAM Secure 为 1024 KiB。

## 8. e² studio 烧录快捷键

- `F11`：启动最近一次 Debug 配置，通常会连接并下载，但可能停在程序入口。
- `F8`：Resume，让暂停的程序继续运行。
- 红色方块/Terminate：终止当前调试会话。
- Disconnect：断开调试连接但不一定复位目标。

比赛联调优先使用命令行 J-Link，e² studio 用于 FSP Generate、断点和寄存器诊断。

## 9. 烧录后快速验收

1. LCD 出现正常实时画面，颜色和方向正确。
2. SCI9 有启动日志，无连续致命故障。
3. USER 按键冻结 -> 推理/显示框 -> 再按恢复预览。
4. ESP8266 获得 IP，手机/电脑打开 `http://<IP>/`。
5. 网页温湿度、光照、网络和 SD 状态更新。
6. 当前无底盘能力时，运动按钮保持禁用、地图显示规划预览。

## 10. 回退

底盘/串口屏集成导致黑屏、AI失败或无法联网时，先烧回本交付包 SREC。若只是 M33 运动工程
失败，禁用电机驱动并恢复 M85 单核基线，不破坏 camera 工程。任何回退都保留失败日志和配置
差异，不能用覆盖文件的方式消灭证据。
