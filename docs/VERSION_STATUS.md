## 2. 产品快照（2026-08-18）

以下概括保存的 `camera` 源码与当时交付记录的版本边界。开发期交接和调试文档已移至本地归档。

- 目标器件 `R7KA8P1KFLCAC`、CPU0 / Cortex-M85、FSP 6.5.0、GNU Arm Embedded 13.2.1。
- 产品侧包含 OV5640、ST7796S、YOLOX/Ethos-U55、环境采集、ESP8266 局域网网页和 SD 链路。
- 当时的网络方案为 HTTP / WebSocket 局域网服务，交付记录明确写明不接云平台。
- M33 底盘、JY61P、ZDT42、串口屏板端集成与整田自动巡检在该记录中尚未完成。
- 模型语义一致性测试与田间小麦识别精度合格分别判断；交付状态表仍要求优化小麦识别准确率。

## 3. 提交报告与附录代码

报告简介描述双核分工、INT8 模型、分块去重和 OneNET 上传，是提交材料中的系统方案。`report_core` README 明确要求补充实际开发板、FSP、模型编译器和张量参数。

附录示例采用 320×320 RGB INT8；`camera` 的 YOLOX tile224 路线有独立张量、颜色顺序和量化契约。两套代码不能直接混用，不以报告附录替代产品主工程。

## 4. 串口屏后续材料（2026-08-19）

最终协议晚于 08-18 快照，定义 `@P1` 等上行帧，以及两个方向不同的帧结束符。HMI 文件存在不能证明协议已接入该产品快照，需对照代码完成板端联调。
